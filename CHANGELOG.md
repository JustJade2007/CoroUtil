# Changelog

## [1.3.9] - Minecraft 26.3
- Ported CoroUtil Fabric to Minecraft 26.3 ("Wilderness Bound").
- Upgraded target Java runtime to Java 25.
- Upgraded Fabric Loader to `0.20.1` and Fabric API to `0.166.2+26.3`.
- Updated ForgeConfigAPIPort to `26.3.1` (API v5).
- Adapted permissions in commands to Minecraft 26.3 `PermissionCheck` / `Commands.LEVEL_GAMEMASTERS`.
- Updated `CoroUtilColor` to use `ModelManager.getBlockStateModelSet().getParticleMaterial(...)`.
- Updated `coroutil.accesswidener` to official namespace and verified all access widener entries.
- Upgraded Fabric Loom toolchain to `1.20.0-alpha.31` and Gradle wrapper to 9.9.1.
